# 万端 API 社区

万端 API 是面向开发者与模型的开放能力平台。当前提供中国大陆节假日、调休和工作日计算能力，并支持 REST 与 MCP。

本仓库是万端 API 的公开社区入口，用于收集问题、交流使用经验和讨论产品建议。

## 快速入口

- [开发者文档](https://docs.wanduanapi.com)
- [公开 API](https://api.wanduanapi.com)
- [提交问题](https://github.com/wanduanapi/wanduan-community/issues/new/choose)
- [参与讨论](https://github.com/wanduanapi/wanduan-community/discussions)

## 请选择合适的入口

- 发现 API 或 MCP 行为异常：提交 [问题](https://github.com/wanduanapi/wanduan-community/issues/new/choose)。
- 发现节假日数据可能有误：提交数据修订问题，并附上国务院或国务院办公厅等权威来源。
- 发现文档错误：提交文档问题，并附上对应页面地址。
- 想咨询用法、交流方案或提出开放性建议：前往 [讨论区](https://github.com/wanduanapi/wanduan-community/discussions)。
- 发现安全漏洞：请先阅读 [安全说明](SECURITY.md)，不要在公开 Issue 或 Discussion 中披露细节。

## 仓库边界

本仓库不包含万端 API 的业务源码、生产部署配置、数据库凭据或内部运维脚本。API 服务、领域规则、数据集和文档站源码继续由组织内的私有仓库维护。

落地页和开发者文档会通过公开地址提供访问；落地页上线后，本仓库的主页链接和 README 会同步更新。

## 参与社区

提交反馈前，请先确认问题尚未被报告，并尽量提供可复现的请求、响应、发生时间和 `requestId`。请不要提交访问令牌、密钥、个人信息或其他敏感内容。

更多约定见 [贡献指南](CONTRIBUTING.md) 和 [行为准则](CODE_OF_CONDUCT.md)。
