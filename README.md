# 万端 API 社区

这里是万端 API 的社区空间。你可以在这里反馈问题、核对节假日数据、交流接入经验，也可以和我们讨论接下来值得做什么。

万端 API 面向开发者和模型提供可直接调用的能力，目前先从中国大陆节假日、调休和工作日计算开始，支持 REST 与 MCP。

## 从这里开始

- [查看开发者文档](https://docs.wanduanapi.com)
- [开始第一次 REST 请求](https://docs.wanduanapi.com/products/china-calendar/rest/quickstart)
- [报告问题](https://github.com/wanduanapi/wanduan-community/issues/new/choose)
- [参与讨论](https://github.com/wanduanapi/wanduan-community/discussions)

## 你可以在这里做什么

- 接口或 MCP Tool 返回结果不符合预期：请[报告问题](https://github.com/wanduanapi/wanduan-community/issues/new/choose)，尽量附上可复现的请求和响应。
- 发现节假日、调休或补班数据可能有误：请提交数据修订建议，并附上国务院、国务院办公厅等权威来源。
- 发现文档中的错误或遗漏：请提交文档反馈，并附上对应页面地址。
- 想咨询用法、分享接入经验或提出开放性建议：欢迎到[讨论区](https://github.com/wanduanapi/wanduan-community/discussions)交流。
- 发现安全问题：请先阅读[安全说明](SECURITY.md)，不要在公开 Issue 或 Discussion 中披露细节。

## 提交反馈前

请先搜索已有的 Issue 和 Discussion，确认问题还没有被提出。反馈越具体，越容易得到处理：请求示例、实际响应、发生时间和 `requestId` 都很有帮助。

请不要提交访问令牌、密钥、个人信息或其他敏感内容。如果不确定该发在哪里，直接到 Discussion 提问即可。

更多参与约定见[贡献指南](CONTRIBUTING.md)和[行为准则](CODE_OF_CONDUCT.md)。
